# 生活广播一直听

好生活，听我的

## 开发愿景

阿基米德fm在 2026/4/1 之后对广播主页做了一次大改动，隐藏了所有广播的回听列表，并且持续冷归档历史回听节目，安徽生活广播（也包含安徽音乐广播、安徽经济广播、安徽交通广播等）的回听功能已无法使用

项目作者与安徽生活广播听友群的听友们非常不希望看到这样的事情发生，曾通过小程序渠道，阿基米德fm客服渠道，邮箱渠道分多次向阿基米德发出建议恢复节目回听功能，就算付费我们也是支持的，可惜直到现在暂无官方回复

不过通过对阿基米德fm的节目获取接口的分析（感谢 [coco292931/ajmide-archive-downloader](https://github.com/coco292931/ajmide-archive-downloader) 对阿基米德fm的节目接口详细分析）后，项目作者幸运的找到了并未被冻结的安徽生活广播（含改版前安徽城市之声主页）的节目回听

仍可惜的是，仅安徽生活广播回听渠道未被阿基米德fm平台冻结，余下的安徽音乐广播、安徽经济广播、安徽交通广播的回听均宣布被阿里云 OSS 深度冷归档了，只能期盼阿基米德fm能早日改版主页成功，恢复对往期节目的访问权限

本项目通过缓存阿基米德fm对安徽生活广播往期节目的 `c_id` 桶标识符，拼接能指向往期节目的 `ia-bk-i.ajmide.com` 音频链接，并通过 Github Actions 每晚零点更新节目的 OPML 清单，供听友导入自己的播客软件进行回听，后续还会提供相关的网站供大家了解安徽生活广播这个频率的历史

直播节目仍建议前往阿基米德fm的 [安徽生活广播](https://m.ajmide.com/m/brand?id=10609075) 主页收听，特殊时期情况下支持使用阿基米德fm仍是保留历史回听的不二之选

## 使用方法

### 1. 用播客客户端回听

首先，需要选择适合你的播客播放器，安徽生活广播的回听将以播客的形式呈现

- 苹果端可以使用默认播客播放器 `Apple Podcast` 导入本项目提供的回听
- 安卓端建议下载开源播客客户端 `AntennaPod` 导入本项目提供的回听
- 不建议使用第三方商业播客客户端（诸如小宇宙、喜马拉雅等，会提示版权限制）

[<img src="https://fdroid.gitlab.io/artwork/badge/get-it-on-zh-cn.png" alt="先在此处下载 AntennaPod" height="80">](https://f-droid.org/packages/de.danoeh.antennapod/)

然后，在你的播客播放器中导入本项目提供的动态 OPML 订阅地址

```
https://taoengine.github.io/ahshgb-forever/ahshgb.opml
```

建议听友们打开手头上播客软件的保存缓存功能，存下有价值的历史节目回听，万一阿基米德fm将这最后一点回听内容深度冷归档后，这些曾听过的历史回听仍能保存安徽生活广播的峥嵘岁月

该订阅每晚零点更新

### 2. 在网页上直接回听（仍在开发中...）

直接访问项目托管网站即可

```
https://taoengine.github.io/ahshgb-forever
```

愿景：网站提供分时间，分节目的回听，并介绍安徽生活广播这个频率的历史

网站对应的节目内容每晚零点更新
